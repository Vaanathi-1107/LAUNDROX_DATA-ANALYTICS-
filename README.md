# LAUNDROX – Smart Laundry Management System

## Project Overview
LAUNDROX is a Smart Laundry Management System developed using Python and Streamlit. It helps customers place laundry orders, track order status, and receive email notifications. It also provides dataset visualization and order analytics.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- CSV
- SMTP Email

## Key Features
- Customer Registration and Login
- Multiple Clothing Selection
- Laundry Order Management
- Unique Order ID Generation
- Email Notifications
- Order Tracking
- Admin Dashboard
- Dataset Analysis and Visualization
- Order Analytics Dashboard

## Dataset Visualization
The system provides:
- Dataset Preview
- Missing Value Analysis
- Duplicate Record Analysis
- Numeric Column Histogram
- Category Distribution
- Statistical Summary

## Installation

Install the required libraries:

```bash
pip install streamlit pandas numpy matplotlib python-dotenv
```

## Run the Application

```bash
streamlit run app.py
```

## Email Configuration
Configure SMTP credentials in a local `.env` file.

Never upload passwords or secret credentials to GitHub.
